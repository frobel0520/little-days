# Original synthesized audio

Generated deterministically by `scripts/generate-audio.py` using Python standard-library synthesis, noise, envelopes and damped tones. No recordings, external sample packs or third-party music are used. Paper, cloth, wood, ceramic and metal are stylized material cues, not recordings of real objects. Rain, wind and birds are quiet ambience; radio is an original eight-note motif.

Regenerate with `npm run assets:audio`. All nine assets are mono PCM WAV, 22050 Hz. Audio is off by default; ambience can be disabled separately. Human listening and physical phone speaker validation remain outstanding.
