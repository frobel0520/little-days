# 2026-10-28：部署接入與遊戲打磨

## 本輪成果

- **Harbor**：固定工具與 SHA-512 核對的 Godot 安裝腳本、只接收受信任 App actor 的 release executor、Owner 核准前的 OIDC 提案 workflow、Pages Functions 產物與版本讀回。版本端點不受維護模式擋下，原 Harbor 產生碼另行保留，不手動修改。尚未在 GitHub Actions 或正式 Cloudflare 執行。
- **載入與效能**：引擎原始 37.7 MB 改優先下載 9.5 MB gzip 分片（減少 74.9%），不支援解壓時仍可載入原始分片。新增畫質選項、手機自動畫質、背景降頻／音訊暫停，以及開發用 frame／draw-call 診斷。壓縮不代表 WASM 記憶體需求等比例降低。
- **貓咪與聲音**：獨立頭部會輕微轉動，打招呼時有所回應；修正咖啡店等地面訪客坐進座椅的問題。調整材質反光，加入九種原創程序合成的材質聲、環境聲與短旋律；預設關閉、可立即靜音，環境聲可另關。不是錄製的實物素材，也未取得人類聆聽或手機喇叭品質驗收。
- **可選互動**：收音機、風鈴、布料、植物、澆水壺、相機等可透過選物旁按鈕觸發動作與文字／聲音。擺位與完成計數保持不變，不增加通關工作。
- **備份**：Web 下載與選檔、原生檔案對話框入口、版本／大小／座標驗證、匯入預覽與確認、自動保存匯入前進度，以及可還原的備份。原生對話框尚未在桌面 GUI 驗收。
- **裝置驗證**：雲端 Chromium 實際觸控與四種尺寸，另有桌機；實體 Android／iOS、Safari／WebKit、低階機發熱與耗電仍無實測設備，不能認定完成。

## 驗證與證據

24 項 JavaScript 測試，以及 Godot 的 85 件模型、11 個環境、貓咪姿態、原存檔與新備份格式、九種音訊資源檢查通過。完整瀏覽器流程涵蓋六關收尾、筆記／合照與重載、五個小品、原存檔匯入、手機拖放／取消／橫向。

新增測試使用真實下載與 file chooser 驗證備份預覽、取消、覆蓋、復原、無效檔案與重載；選物互動不改進度。另驗證壓縮資源與原始 fallback、四個手機尺寸，軟體渲染診斷每個場景至少累積 30 個 frame。背景焦點事件以瀏覽器事件模擬驗證，仍需實機切換 App 驗收。

本機 Pages Functions 編譯及部署檔案單檔上限檢查通過；workflow YAML 與安裝腳本語法已檢查。官方工具安裝下載流程尚未在 hosted runner 實跑；正式 profile／secrets／App actor、Owner 核准與平台讀回未驗證。

## 仍需完成的外部步驟

正式部署接入見 [harbor-deployment.md](harbor-deployment.md)：環境草稿新增 API／Harbor 白名單，尚未套用；GitHub API 實際查詢回 Forbidden，沒有 Harbor Owner session，不能在這裡建立或核准正式 profile。須完成 main 合併、供應商設定與 Owner 核准，才能宣稱正式部署成功。

真機條件與量測矩陣見 [device-validation.md](device-validation.md)。目前不能對 Android／iOS 真機效能、瀏覽器記憶體、耗電、發熱或實際音效品質下結論。持續美術與關卡節奏打磨仍是後續產品工作，並非一次改動就全部完成。
