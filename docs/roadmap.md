# 開發待辦與優先順序

更新：2026-10-27。公開部署維持暫停；不阻擋本機與雲端開發。

## 目前已具備

Godot 3D 收納、連續擺位、不同支撐高度、旋轉、撤銷、重整確認、本機存檔、舊存檔匯入、貓咪互動與手動收尾。主線從三關擴成六關，另有五個日常小品。三隻貓的合照約定在第六關收束。

## 下一輪優先

2026-10-28 已完成[玩家角度探索測試](playtest-2026-10-28.md)，並實作五項修正：手機橫向左右配置、按鈕各狀態文字對比、常駐放置按鈕／模型預覽／小物觸控容錯、奶油露面與合照放大展示、下層架透視／選物外框／較完整的附近空位搜尋。原始發現保留在報告中作為修正前紀錄；真機效能、美術與下一季節奏仍待後續。

1. **手機實機與手感**：Android Chrome、iOS Safari 的拿取、捲動面板、縮放、背景恢復與音效啟用。高像素密度瀏覽器模擬已納入流程，仍需要真機回饋。
2. **3D 可讀性與效能**：檢查小物重疊時是否容易辨認、被擋住時能否順利取回；量測低階裝置的載入時間與幀率。以不打斷自由收納為原則調整。
3. **美術與音效**：打磨材質、家具細節與貓咪姿態；以合適的紙、木、陶瓷聲音替換合成短音，檢查音量與重複播放的疲勞感。
4. **六關試玩節奏**：觀察玩家是否讀到關卡間的線索、是否理解「手動收尾」與相框變化，以及哪一關會想多停留。

## 已完成的本輪內容

- 第四關咖啡店：雨天的等待、街坊邀請卡、芝麻對老歌的回應。
- 第五關屋頂：收布旗、聽風鈴、墨墨逐漸願意靠近。
- 第六關庭院：三隻貓一起出現，收尾後空相框變成新的合照，筆記更新為完成後的文字。
- 茶壺、收音機、編織籃、風鈴模型；24 件新增的敘事小物與六個可選小習慣。
- 依每關資料決定貓咪休息位置、訪客與結尾下一站，後續加關卡不必再依賴前三關的硬編碼。
