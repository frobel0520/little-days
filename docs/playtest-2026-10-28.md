# 2026-10-28 玩家角度探索測試

受測版本：`aef9828ea1401c9afdaa4e5bb70d06095a3f6d64` 的 Godot Web 建置。評估偏好為喜歡貓咪、休閒小品與自由收納的玩家。由 Chromium 實際滑鼠／觸控事件操作，配合畫面檢視與唯讀狀態觀察；不是人類受測者訪談，也不是手機真機驗收。

## 範圍與結果

- 桌機 1360×920：從新存檔依序完成六個主線故事，逐關閱讀收尾；三隻貓皆見面、打招呼，筆記記錄十五個小習慣。
- 直接從箱中拖曳杯子到桌面，直接點奶油打招呼；其他物品混用清單選取與不同高度的家具按鈕，並非每件物品都用手動拖曳通關。
- 最後空相框變成三隻貓合照，名稱與故事同步更新；重新載入仍保留完成紀錄、照片與筆記結尾。
- 五個小品逐一載入，每關選取並放置一件物品；本輪沒有把五個小品全部通關。
- 手機 390×844、DPR 3：直接 touchStart／touchMove／touchEnd 拿起杯子放到桌面成功；透過可捲動面板放置書、毯子、相機，測試放大與直向轉橫向。
- 844×390 橫向出現嚴重版面壓縮，見 P1-01。
- 已完成的主線與直向觸控路徑未收集到瀏覽器例外或 Godot SCRIPT ERROR。這不代表所有輸入組合皆無錯誤。

## 整體判斷

自由擺放、不計時、由玩家決定何時收尾，符合休閒收納的方向。物品短文與舊照片、相冊、新合照的連續故事值得保留。貓咪可選的互動沒有變成通關壓力，也是優點。

目前仍有明顯原型感：收納時常需回到清單找物件，貓咪回饋以文字為主；六關的操作差異小。下一輪應優先打磨辨識、操作與貓咪表現，再擴充關卡。

| --- | --- | --- | --- |
| P1-01 | 手機由 390×844 轉成 844×390：下方面板遮住大部分場景，清單可視高度從約 194 壓縮成約 28 CSS 像素。另以全新 context、預設鏡頭直接開橫向，也重現相同 28 像素清單。截圖 `preview-player-mobile-landscape.png`、`preview-player-landscape-default.png`。 | 難以看清場景，也放不下一排完整物品按鈕，橫向無法舒適遊玩。 | 改用適合短螢幕的左右配置或可收合面板。驗收直向轉橫向及直接開橫向後，場景、物品清單與放置操作皆可見且可用。 |
| P1-02 | 多個收尾對話框中，「回到房間」有白字落在淺色背景、幾乎看不見的情況。另在貓咪筆記保持按鈕焦點、將指標移離及移入，兩種畫面皆重現淺色文字。截圖 `preview-player-dialog-focus.png`、`preview-player-dialog-hover.png`。 | 玩家可能以為沒有離開按鈕；鍵盤焦點也不容易辨認。 | 明確設定按鈕 hover／focus／pressed 等狀態的文字顏色，逐狀態驗收。 |
| P2-01 | 手機預設視角的小物很小；直向面板的物品、故事、放置表面分布在不同捲動位置。截圖 `preview-player-mobile-start.png`、`preview-player-mobile-arranged.png`。 | 玩起來容易變成清單選物加選家具，減少親手收納的樂趣。 | 選物時給清楚的輪廓／預覽；縮短選物到放置的操作距離，調整鏡頭與觸控容錯。驗收箱內相鄰小物可容易辨認並取回，避免只能依賴名稱。 |
| P2-02 | 第一關整理兩件後，文字顯示奶油探頭，但初始角度下牠仍被相機與盆栽等物件遮住。截圖 `preview-player-cat-peek.png`。 | 愛貓玩家可能錯過首次露面的獎勵。 | 第一次露面安排在可看見的位置，輔以短暫動作或提示；不增加強制等待。驗收不用搬開其他物品就能辨認探頭的奶油。 |
| P2-03 | 第一關盆栽放下層架後，葉子被上層板遮住；咖啡店等場景同一表面的物品仍可能明顯穿插。截圖 `preview-player-home-arranged.png`、`preview-player-cafe-arranged.png`。 | 有自由擺放，但成品的可讀性與整理後的滿足感受損。 | 改善遮擋提示、取回輪廓與附近位移，檢查家具層高。保留容許重疊的規則，不改成唯一解或強制擺位。 |
| P2-04 | 第六關合照已生成，但立即出現的收尾對話框遮住場景；關閉後照片只是場景中的小模型。截圖 `preview-player-courtyard-ending.png`、`preview-player-final-photo.png`。 | 連續六關的故事回報容易只在文字裡被讀到。 | 收尾先展示或放大合照，再進文字；提供再次欣賞入口。驗收玩家不必自行尋找小相框就能注意到新照片。 |

## 同日修正

以上問題保留為修正前紀錄。本輪已實作：

- 橫向短螢幕使用左右配置；直向將家具按鈕固定在捲動區外。手機物品故事與便條改由固定入口開啟，選物後不用捲到清單底部找家具。
- 明確設定焦點、hover、按下等狀態的深色文字，保留焦點外框。
- 選取小物顯示獨立 3D 模型預覽與可穿過遮擋的選取外框；手機點空時增加附近射線容錯，精準命中的物件仍優先。
- 奶油探頭的位置移到箱旁可見處，貓咪換位置以短暫移動銜接；第六關收尾對話框直接展示合照模型，之後可從相框故事再次欣賞。
- 下層架有物品時淡化上層結構；放置物品時檢查更多連續座標空位與鄰物邊界，減少物體穿插。擁擠時仍容許放置，不加入硬性通關擺法或真實堆疊。

修正後證據使用 `preview-fixed-` 檔名前綴，與修正前截圖分開保存；驗證結果見開發進度。

## 驗證限制

使用軟體 WebGL 的雲端瀏覽器，不能據此判斷實體 Android／iOS 的幀率、耗電、發熱、觸感或網路載入效能。本輪未聆聽實際音訊，不對音效品質下結論；未測正式網站、發布流程、瀏覽器跨裝置同步。所有測試使用隔離的 playtest 存檔，未寫入玩家正式存檔。
