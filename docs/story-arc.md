# 街角的貓：第一季六個午後

## 敘事主線

玩家從搬家開始，透過每天幫一點小忙，慢慢成為街坊的一員。前半段認識奶油、芝麻與墨墨；後半段讓已熟悉的人與小物重新相遇。第一季的收束是拍下「現在的牠們」，不是解開謎題或收集滿所有筆記。

| 關卡 | 這一天發生的事 | 接到下一站的線索 |
| --- | --- | --- |
| 01 箱子裡的新室友 | 新房間裡已經有一位紙箱住戶 | 相機裡的舊合照指向花店 |
| 02 花店的窗邊 | 芝麻認得舊毛巾，也記得街坊 | 合照與訂單簿連到書店 |
| 03 書架後的一雙眼睛 | 墨墨開始願意留在玩家面前 | 相冊最後一頁留白，雨聲引向咖啡店 |
| 04 雨停以前的窗邊 | 一起等雨停，替朋友留一只杯子 | 邀請卡、空籃與木夾子帶玩家上屋頂 |
| 05 風把午後吹乾了 | 收起布旗，給墨墨自己靠近的時間 | 墨墨跟向樓梯，庭院傳來擺杯子的聲音 |
| 06 相冊裡的今天 | 街坊帶來各自的小物，三隻貓都在 | 空相框成為新合照，留下一點日常的餘韻 |

## 小物的回聲

- 第一關多留的杯子，在咖啡店與庭院成為「有人會來」的具體回應。
- 花店的種子與書店的窗邊，在屋頂的小苗再次連起來。
- 咖啡店的空籃、木夾子與老收音機，隨街坊移到下一個場景。
- 第一關的相機、第三關的相冊，在最後一關一起出現。
- 奶油從陪人拆箱，到願意把毯子的一角留給其他鄰居；芝麻從舊照片走進今天的照片；墨墨從躲藏，到自己跟上大家。

物件跨關出現是敘事連續性，不是要玩家攜帶或交付道具。每關仍可獨立開始，各關進度獨立保存。

## 互動原則

收納不用指定答案、精準擺位或等待動畫。物品故事與貓咪小習慣提供多看一眼的理由，不作為完成門檻。三隻貓可以在庭院一開始就看見；墨墨整理到一半後會改成坐姿，讓靠近有漸進的回應。

最後的相框起初留白，只有玩家按下「今天收好了」後，模型才換成三隻貓的合照。照片隨完成紀錄保存，重新整理或回到關卡仍保留。貓咪筆記也從「等著下次合照」改成已經發生的今天。

## 後續故事空間

合照旁的空白可延伸季節小事，例如修一盞路燈、整理河邊野餐或冬天的店門口。暫時不引入失蹤、限時營救、強制收集或沉重的悲劇線，維持安心、可隨時停下的節奏。
