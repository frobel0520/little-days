# 裝置與效能驗證

已執行雲端 Chromium 的真實滑鼠／觸控事件，並以 390×844、844×390、360×740、932×430 與 DPR 3 檢查介面。這是軟體 WebGL；不能代替實機幀率、記憶體、發熱、耗電與 Safari 音訊政策。

此環境未提供實體 Android／iOS，沒有 Android 裝置工具，WebKit／Firefox 引擎亦未安裝。因此上述裝置與跨引擎結果保持未驗證，不以 Chromium 的 mobile flag 代稱 Android／iOS 測試通過。

## 已提供的量測與優化

- 引擎原始 37,700,666 bytes，分片 gzip 共 9,473,572 bytes，下載量減少 74.9%；不支援 DecompressionStream 的瀏覽器回退原始分片。仍需足夠記憶體載入解壓後 WASM，不宣稱記憶體減少 75%。
- 省電模式上限 30 FPS、關閉即時陰影；細緻模式上限 60 FPS。自動模式針對小／短螢幕採省電策略。模式會保存，玩家可手動切換。
- 失去焦點取消拿取、暫停環境聲，降為 10 FPS；恢復焦點回復設定。這是背景降頻，不保證特定作業系統的背景生命週期。
- `?playtest=1` 唯讀診斷包含最近最多 600 frame 的 p95 毫秒與繪製呼叫。`python3 game/tests/features_smoke.py` 會將本地載入、資源 bytes 與軟體渲染樣本寫到 `/tmp/little-days-performance.json`。這份資料只供同環境比較，不作為手機效能承諾；本輪樣本保存在 [performance-local-2026-10-28.json](performance-local-2026-10-28.json)，每個診斷情境至少累積 30 個 frame，並非手機暖樣本基準。

## 真機待驗收矩陣

Android Chrome 與 iOS Safari 各需：首次與重複載入、拿起／轉向／取消／捲動／橫向切換、背景恢復、開啟音效、備份下載／檔案挑選／匯入／還原、六關收尾與合照。記錄 OS／瀏覽器版本、畫質、測試情境與失敗步驟；不記錄裝置序號或個人帳號。

載入與動態遊玩分開量測；低階手機記錄至少 30 個暖樣本、frame p50／p95、卡頓與記憶體警告。發熱／耗電應在實體裝置持續遊玩後回報，不能從雲端 CPU 推估。
