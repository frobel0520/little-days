# 《小日子收納》美術與技術基準

更新：2026-10-01。使用者指定參考：[《囈語小鎮 / Whisper of the House》官方 Steam 商店](https://store.steampowered.com/app/2589500/?l=tchinese)。已實際查看官方展示與商店說明；以下區分觀察、設計選擇與未確認事項。

## 參考觀察

- 官方展示採等角視角的房間切面與像素美術。牆、地板、家具和小物具有一致方向與比例；家具可辨認上面、正面、側面。
- 收納場景包含多種表面與容器，例如地板、桌面、櫃子及層架；畫面立體感不只是對整幅平面做傾斜。
- 官方說明包含搬家、整理、清潔、家具裝飾、可互動的小物與物件音效。生活情境與整理前後的差異支撐遊戲體驗。
- 官方商店未公開完整渲染或物理架構。不能從畫面證明其內部是純 2D、3D 模型、預渲染素材或混合方式，也不能把推薦給本專案的技術說成參考遊戲實作。

## 本專案採用的美術基準

參考其等角構圖、可辨認的物件體積、生活密度與光影層次。延續使用者先前要求的簡潔線條與可愛氛圍；像素化不是本輪已確認的必要變更，素材不使用原遊戲內容。

1. **場景**：以一個可收納的小房間角落作為下一個驗證單位。房間有地板與兩面牆，家具至少有書桌、層架、抽屜。保留五個日常題材，先驗證一個場景再擴展。
2. **視角**：固定等角視角，場景地面、家具和物品共同遵守同一組投影軸。牆面維持直立，不把所有素材一起壓扁。
3. **物品**：每件有自己的尺寸、接地錨點、頂面／側面與接觸陰影。相機是可辨認的立體相機，信封是薄物件，水壺具有高度；不以通用色塊作外框。
4. **配色**：暖木色、奶油白、柔和綠與蜜桃色；以局部明暗和輪廓呈現材質，避免全畫面低對比。
5. **生活感**：物品原本就在桌上或搬家箱中，整理後能看到整體場景變化。遊戲場景應成為主畫面，減少目前卡片清單的存在感。
6. **動作**：拿起有輕微浮起與陰影分離，落下有短暫緩動；紙、木盒與陶瓷使用不同的柔和回饋。音效須有可用的靜音控制，未經互動不自動播放。

## 技術選擇：瀏覽器 2.5D 場景

推薦 TypeScript + PixiJS 的場景與獨立精靈素材，頁面導覽及可及性控制保留 HTML。這是針對本專案的架構建議，尚未遷移目前原型。

- PixiJS 提供場景圖、Container／Sprite、可控渲染順序與滑鼠／觸控 pointer events，符合固定視角、多物件操作的需求。[場景圖](https://pixijs.com/8.x/guides/concepts/scene-graph)、[互動事件](https://pixijs.com/8.x/guides/components/events)。
- 每件物品以獨立素材繪製頂面與側面。轉向切換對應方向素材，不旋轉整張精靈冒充不同視角。
- 模型座標使用連續 `x, y, elevation`；畫面位置由固定等角投影產生，無可見棋盤與格子吸附。
- 每件物品記錄 `size`、`anchor`、`footprint`、`height`、`orientation` 和 `supportSurfaceId`。
- 桌面、層架、抽屜和地板是獨立可放置表面，記錄範圍與高度。拖放由螢幕座標反算到候選表面，不能只靠 zIndex 假裝放在桌上。
- 遮擋依接地點、表面關係與物件體积決定，不以最後放下的物品永遠置頂。牆面可淡化，讓被擋住的小物仍能選取。
- 不採用剛體物理作為核心。穩定的放置與短落下動畫更符合放鬆需求；若之後需要自由鏡頭或真實翻倒堆疊，再評估 Three.js 或其他 3D 引擎。
- 不需要安裝 Unity Editor；繼續以瀏覽器預覽、靜態部署和裝置本機儲存為初期交付方式。

## 寬鬆收納規則

- 不要求填滿空間、唯一解、精準對齊或倒數完成。
- 放置表面允許合理疊放；先作柔和調整，避免物品完全穿進家具或被另一件吞沒。調整不能扣分或要求玩家反覆對齊。
- 物品全部離開待整理區、進入可收納表面就能完成。最後由玩家按「今天收好了」收尾，避免自動彈窗打斷最後的擺設。
- 完成後仍可繼續裝飾。建議位置只作參考，沒有必須服從的答案。

## 下一個可驗證版本

先製作一個房間角落、三種可放置表面和約八件比例不同的物品。驗收：

- 靜止畫面能辨認牆、家具側面與物品高度；不是目前的平面傾斜抽屜。
- 物品可拿起、轉向並移到不同高度的表面，滑鼠與觸控的位置準確。
- 前後遮擋合理，被遮住的小物仍能取回。
- 任意合理擺法都能完成；完成後仍可整理。
- 手機可縮放／移動畫面，控制不依賴鍵盤。

此文件定義下一版基準，不表示以上房間場景、PixiJS 遷移、表面支撐、音效或手動完成已在當前原型實作。
