# 小日子收納 · Little Days 3D

以 **Godot 4.6.3** 製作的 3D 收納遊戲。房間、家具、小物與貓咪皆為真正的立體幾何，採固定等角鏡頭、暖色材質與光影。可拿起、連續轉向、移到不同高度的家具表面，放下時帶有短暫緩動與接觸回饋。

## 內容

主線六關保留原有委託、物品故事、貓咪筆記與收尾劇情：

| 關卡 | 空間 | 小物 | 貓咪 |
| --- | --- | --- | --- |
| 箱子裡的新室友 | 午後的房間 | 7 件 | 奶油 |
| 花店的窗邊 | 街角花店 | 8 件 | 芝麻與奶油 |
| 書架後的一雙眼睛 | 巷口舊書店 | 8 件 | 墨墨與奶油 |
| 雨停以前的窗邊 | 轉角咖啡店 | 8 件 | 芝麻與奶油 |
| 風把午後吹乾了 | 公寓屋頂 | 8 件 | 墨墨與奶油 |
| 相冊裡的今天 | 街角小庭院 | 8 件 | 奶油、芝麻、墨墨 |

另將原有五個抽屜小品轉成 3D：書桌抽屜、野餐籃、週末行李、手作盒、搬家紙箱。合計 **11 個日常、85 件小物**。各種相機、書、陶杯、植物、花束、花瓶、澆水壺、相框、閱讀燈、布料、包袋、眼鏡、食物，以及新加入的茶壺、收音機、籃子與風鈴皆有對應模型。

第四至六關接續書店的相冊約定；最後按「今天收好了」，空相框會變成三隻貓的新合照，並隨完成紀錄保留。故事設計見 [第一季故事弧](docs/story-arc.md)，後續工作見 [開發待辦](docs/roadmap.md)。

沒有方格、倒數或唯一擺法。容許重疊，靠近時會輕輕尋找較空的位置；主線只需要把小物拿出箱子，再由玩家按「今天收好了」收尾。貓咪露面、打招呼與小習慣不作為通關門檻。收尾後仍可繼續整理。

## 執行

需要 Godot 4.6.3、對應的官方 Web export templates，以及 Node.js 22+：

```sh
npm ci
npm run build
npm run dev
```

開發伺服器使用 4317 埠，首頁 `/` 為 Godot 3D 版。建置腳本會匯出內容資料、匯入 Godot 資源並產生 `game-build/`。雲端已準備好 Godot 與 Web templates；腳本會自動使用 `/workspace/godot-data` 中的模板。其他機器請先從 Godot 的 Export Template Manager 安裝相同版本模板；可用 `GODOT_BIN` 指定執行檔。

本機也可用 Godot 開啟 [game/project.godot](game/project.godot)，待資源匯入完成後按 F5 執行，不依賴瀏覽器或後端。雲端的無介面流程可匯入、測試及匯出；互動編輯場景需要桌面介面。

## 操作

- 滑鼠／單指拖曳場景中的小物。拿起時抬高並隨移動傾斜，放手落到支撐表面。
- 可從清單選取被遮住的小物，再點家具按鈕放置；清單與家具面板在手機上可捲動。
- R 或「轉向」轉 90 度，模型連續旋轉；Esc 或拖到「取消」放手可取消拿取。沒有拿取時，「取消」解除選取。
- 點選重疊處可輪流換選；拖動優先拿起已選的小物。
- 「換角度」切換鏡頭；滾輪或「放大／縮小」調整大小。未選取小物時，拖動空白處移動畫面；F 恢復完整視野。
- 「撤銷」退回上一步；「重整」需確認，可再撤銷。貓咪筆記與過往完成紀錄會保留。
- 音效預設關閉，可手動開啟；已有紙、布、木、陶瓷、金屬等原創程序合成聲，並依場景播放雨、風或鳥聲。設定中可獨立關閉環境聲。
- 沒有選取小物時，可輕點場景中的貓咪打招呼，也可使用面板上的招呼按鈕。

手機橫向採左右配置，直向的家具放置按鈕固定在清單下方；選取小物時可看放大模型預覽，點「小故事」閱讀內容，未選取時同一入口可讀便條。小物外框可穿過遮擋辨認；使用下層架時，上層結構會淡化。放置時會優先尋找附近空位，空間擁擠仍允許完成，不要求唯一擺法。第六關收尾會直接展示放大的新合照，之後可從相框的「小故事」再次欣賞。

## 存檔

Godot Web 版使用新的 `little-days-godot-v1` localStorage，原生版使用 Godot 的 `user://` 儲存空間。首次在相同網站來源開啟 Web 版，會匯入先前的三關存檔、貓咪筆記、早期單房間進度與五個抽屜小品存檔；原存檔不會被覆寫。

設定中的「匯出進度備份」會下載 JSON 檔，可在另一裝置「匯入進度備份」。匯入前先顯示確認，並自動保存目前進度；可用「還原匯入前的進度」復原。檔案格式或座標無效時整份拒絕，不會部分覆寫。

進度仍是各裝置、各網址分開保存，沒有雲端同步。更換網域／埠號或從網頁移到原生 App 不會自動帶入存檔。`?playtest=1` 使用獨立測試存檔，不讀玩家進度，並提供唯讀的 `window.littleDaysState` 給瀏覽器測試。

## 結構與驗證

- `game/scripts/art.gd`：全部小物、家具、房間、貓咪的實體幾何；靜態幾何按材質合併，減少繪製呼叫。
- `game/scripts/game.gd`：3D 拾取、表面選擇、拖放、鏡頭、動畫、故事流程與音效。
- `game/scripts/rules.gd`：連續座標、支撐高度、旋轉尺寸、寬鬆完成與存檔位置驗證。
- `game/scripts/interface.gd`：桌機／手機介面、清單、家具按鈕、筆記與對話框。
- `game/scripts/storage.gd`：Web／原生存檔、舊版本匯入與格式清理。
- `site/levels.js`、`site/second-act.js`、`site/cat-behavior.js`、`site/model.js`：保留原作者內容作為單一資料來源。修改後執行 `npm run content` 或 `npm run build` 更新 `game/data/content.json`。

```sh
npm test
npm run test:godot
# 先完成 build 並啟動 dev；需 Python Playwright 與 Chromium
python game/tests/browser_smoke.py
```

原生測試涵蓋 85 件模型的實際幾何尺寸、三隻貓各姿態、各表面的旋轉與邊界、完成條件及損壞存檔。瀏覽器測試使用真實滑鼠／觸控輸入，涵蓋六關收尾、五個小品、不同表面高度、取消、撤銷、貓咪筆記、重載與舊存檔匯入。手機模擬包含高像素密度的直向畫面；不取代 Android／iOS 實機驗證。

## 建置、部署與舊版

`game-build/` 是可部署的靜態 Web 產物，不提交至 Git。Godot 使用單執行緒 Compatibility/WebGL 2 renderer，不需要跨來源隔離標頭。引擎 WASM 由建置腳本拆成每份最多 12 MiB 的靜態檔，載入時以串流重組，符合靜態主機的單檔大小限制；不修改引擎二進位。

`npm run deploy` 會先建置 Godot 版，再透過 Wrangler 部署 `game-build/` 至原 Cloudflare Pages 專案。需要原有部署權限；開發測試不會自動發布網站。既有 Pages Functions 的健康檢查與維護 middleware 保留。

原本 PixiJS 三關與五個 2D 抽屜版本保留在 `/archive/` 作為歷史參考；原本的一桌三物 Godot 手感研究保留在 `prototypes/tabletop-3d/`，可用 `npm run prototype:build` 建置，開發路徑為 `/tabletop-3d/index.html`。主要開發入口已改為完整的 Godot 遊戲。

新增的風鈴、收音機、植物、布料等可透過選物旁的按鈕互動，不影響進度或通關條件。設定提供自動／省電／細緻畫質；省電上限 30 FPS 並關閉即時陰影，背景降頻並暫停環境聲。

Harbor 執行器、提案 workflow 與正式啟用條件見 [部署接入](docs/harbor-deployment.md)，真機驗證與效能界線見 [裝置驗證](docs/device-validation.md)。`npm run test:browser` 包含六關通關、觸控與備份／還原／互動／多尺寸測試。引擎分片優先下載 gzip，載入時串流解壓；不支援時保留原始分片相容路徑。

模型目前採程序生成的簡潔風格，後續可替換為更細緻的模型與材質。尚未加入物品真實堆疊、剛體翻倒、自由尋路、付費或 Android／iOS 安裝包。字體為 Noto Sans CJK TC 子集，授權見 `game/assets/FONT-LICENSE.txt`。
